rclone-personal

rclone-personal is a personal-use application that uses rclone to access Google Drive through the Google Drive API.

The application is used by its owner to transfer, synchronize, and manage personal files between Google Drive and local or cloud computing environments.

This application is not offered as a public service. Google Drive access is authorized by the account owner.

Privacy Policy

This application uses rclone, an open-source file synchronization tool.
