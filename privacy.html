Privacy Policy

Last updated: October 16, 2026

About This Application

rclone-personal is a personal-use application that uses the open-source rclone tool to access the owner's Google Drive account.

Google Drive Data Access

With the owner's authorization, the application can view, create, modify, download, upload, and delete files stored in Google Drive.

How Data Is Used

Google Drive access is used to transfer, synchronize, and manage personal files, including music files, AI-generated audio, and project resources between local devices, Google Drive, and cloud computing environments such as Google Colab.

Data Storage and Sharing

Files remain in the owner's selected storage locations. OAuth credentials are stored in the owner's rclone configuration and must be protected from unauthorized access.

This personal application does not operate a public backend or intentionally collect or sell user data. Files may be processed by the storage and computing services selected by the owner.

Data Retention and Deletion

The owner controls file retention and deletion in their storage locations. OAuth access can be revoked through Google Account settings.
